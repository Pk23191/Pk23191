### [CampusAssist AI](https://github.com/Pk23191/mits-chat-assist-)
A document-grounded campus assistant built around retrieval-augmented generation (RAG), with a FastAPI backend, ChromaDB retrieval, and Gemini/local Ollama inference.

An early project space connected to my interest in AI-driven rural and agricultural decision intelligence.
